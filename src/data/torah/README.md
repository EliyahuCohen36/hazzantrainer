# Torah text

The files in this folder contain the text of the Torah from **Miqra According
to the Masorah** (MAM), prepared by Seth (Avi) Kadish at Hebrew Wikisource,
with technical assistance from Erel Segal-Halevi and Benjamin Denckla.

Source: [Hebrew Wikisource – Miqra according to the Masorah](https://en.wikisource.org/wiki/User:Dovi/Miqra_according_to_the_Masorah#beginning),
via MAM-simple (https://github.com/bdenckla/MAM-basics).
License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
These files are shared under the same license.

Changes made here: converted to a compact JSON format (see index.ts); in the
10 places where MAM notes that Sephardic Torah scrolls spell a word
differently, the Sephardic spelling is used; the paragraph break after
Vayikra 7:21, absent in Sephardic scrolls, is removed; the Ten Commandments
and Bereshit 35:22 are given with the ta'am tahton.
